🚗 Anchor example for this unit: a self-driving car in Pune traffic
  • Hard computing is the odometer or fuel meter: exact input, exact output.
  • Fuzzy logic handles braking: "car ahead fairly close, so brake slightly".
  • Neural network handles vision: recognises pedestrians, cows and signals.
  • Genetic algorithm handles routing: evolves the best route.
  • Swarm intelligence handles the fleet: cars share traffic like ants share pheromone.

1. Using the tracker

  • Tap a question to open or close its answer. Questions tagged no answer yet have nothing to open.
  • ✓ marks a question Completed. ↻ marks it Needs revision. The counters and progress bar update at once.
  • Use the chips All / Pending / Completed / Revise to filter, and the search box to find a question by words or number (e.g. 26).
  • Reset progress (under the filters) clears only your ✓/↻ marks. Your answers stay.
Everything is saved only in this browser on this device. Opening the page on another device or from another link starts empty. Use Backup / restore to move your marks and answers across.

2. Adding answers

  1. On the Tracker tab, click ＋ Add answers (JSON).
  2. Paste the JSON into the box, or click 📄 Choose .json file(s) and pick one or more files.
  3. Click Add to page for pasted JSON. Files are added as soon as you pick them.

If a question already has an answer, the new one replaces it. If any item is invalid, nothing is imported and an error tells you why.

3. JSON format for answers

{
  "answers": [
    { "q": 8, "answer": "### Hard vs soft\n- Hard: exact\n- Soft: approximate" },
    { "q": 9, "answer": "..." }
  ]
}

These two shorter shapes also work:

[ { "q": 8, "answer": "..." } ]

{ "q": 8, "answer": "..." }

Rules

  • q (or qno / question_no) is the question number, 1 to 50.
  • answer is a non-empty string of Markdown. Write line breaks as \n inside the string.
  • Extra fields such as unit or topic are ignored.
  • A wrapping ```json fence around the JSON is stripped automatically.

5. Share your answers with friends

This downloads one .json file with every answer currently on this page: the built-in ones plus any you added. Your ✓/↻ marks are not included.

Your friend then:

  1. Opens this same page and clicks ＋ Add answers (JSON).
  2. Clicks 📄 Choose .json file(s) and selects your file.
  3. Opens any question. The answers now show, tagged your answer.
Importing replaces any answer your friend already has for the same question. To move marks as well as answers between your own devices, use Backup / restore instead.
