1. Using the tracker

  • Tap a question to open or close its answer. Questions tagged no answer yet have nothing to open.
  • ✓ marks a question Completed. ↻ marks it Needs revision. The counters and progress bar update at once.
  • Use the chips All / Pending / Completed / Revise / Easy / Moderate / Hard / Numericals to filter, and the search box to find a question by words or number (e.g. 25).
  • Reset progress (under the filters) clears only your ✓/↻ marks. Your answers stay.
  • A question with an amber note has a problem in the question bank itself (Q24 is missing its hash functions).
Everything is saved only in this browser on this device. Use Backup / restore to move your marks and answers across.

2. Where the questions come from

The questions are not written into this page. They are read from json/BDA Unit 4 Questions.json, so to fix or add a question you only edit that file and refresh. Format:

{
  "chapter": "Unit 4 - Mining Data Streams",
  "topics": [
    { "topic": "Topic name",
      "questions": [ { "id": 1, "question": "…", "difficulty": "easy", "type": "numerical" } ] }
  ]
}

difficulty is easy, medium or hard. id must be unique across the whole file. type is optional: add "type": "numerical" to a question and it shows up under the Numericals filter.

3. Adding answers

  1. On the Tracker tab, click ＋ Add answers (JSON).
  2. Paste the JSON into the box, or click 📄 Choose .json file(s).
  3. Click Add to page for pasted JSON. Files are added as soon as you pick them.
{
  "answers": [
    { "q": 11, "answer": "### Flajolet-Martin\n- hash each element\n- track trailing zeros" }
  ]
}

q is the question id (see the numbers on the left of each question). answer is Markdown: headings, lists, tables, code blocks for ASCII diagrams, and > … for the green example box. A wrapping ```json fence is stripped. If any item is invalid, nothing is imported.
